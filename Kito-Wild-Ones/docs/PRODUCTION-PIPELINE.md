# Production Pipeline — Kito & the Wild Ones

This document defines the planned studio workflow from idea to published YouTube content.  
**Current phase:** foundation only — do not start Episode 1 production until the creator requests it.

---

## Pipeline overview

```
Idea
→ Story
→ Script
→ Storyboard
→ Character assets
→ Backgrounds
→ Voice
→ Music
→ Sound effects
→ Animation
→ Editing / compositing
→ Subtitles
→ Rendering
→ Quality control
→ YouTube export
→ Shorts export
```

---

## Stage guide

### 1. Idea
- Capture a simple adventure + one little lesson
- Confirm it fits ages ~4–8 and Sunrise Valley
- Store notes under `scripts/` (idea log or episode folder)
- Creator approves the concept before writing continues

### 2. Story
- Expand the idea into a short outline (beginning, middle, end)
- Define the emotional beat and resolution
- Keep stakes gentle and solvable

### 3. Script
- Write dialogue and action suitable for young viewers
- Keep language clear; avoid fear-heavy or complex themes
- Save scripts in `scripts/`
- Creator is the final editorial decision-maker

### 4. Storyboard
- Visualize key beats, camera framing, and timing
- Save boards in `storyboards/`
- Flag needed new props, locations, or character poses

### 5. Character assets
- Use approved designs from `characters/`
- Maintain consistency with `docs/CHARACTER-BIBLE.md`
- Do not invent one-off looks that break the series bible
- No final artwork generation until the creator requests it

### 6. Backgrounds
- Build or reuse Sunrise Valley locations in `backgrounds/`
- Keep environments readable and uncluttered
- Match the series color/mood direction

### 7. Voice
- Record or produce approved character voices into `voices/`
- Match voice direction from the character bible
- Organize by episode and character

### 8. Music
- Add original or properly licensed tracks to `music/`
- Tone: warm, playful, never overwhelming dialogue
- Keep a reusable library for future episodes

### 9. Sound effects
- Collect/create SFX in `sound-effects/`
- Prefer a reusable SFX kit for footsteps, nature, comedy accents, etc.
- Balance levels so effects support, not distract

### 10. Animation
- Animate to storyboard and audio timing
- Prioritize clear acting and readable motion
- Keep production files organized by episode under `episodes/`

### 11. Editing / compositing
- Assemble animation, audio, and titles
- Check pacing for young audiences
- Working edits stay in the episode folder; polished masters move toward `renders/`

### 12. Subtitles
- Add accurate, kid/parent-friendly subtitles
- Keep text on screen long enough to read
- Store subtitle files with the episode package

### 13. Rendering
- Render master files into `renders/`
- Use clear naming: episode number, version, resolution
- Preserve masters; do not overwrite without permission

### 14. Quality control
- Check story clarity, character consistency, audio sync, subtitle accuracy
- Confirm age-appropriateness and original-IP compliance
- Creator signs off before publish exports

### 15. YouTube export
- Export platform-ready files into `exports/`
- Prepare title, description, tags, and thumbnail (`thumbnails/`)
- Follow the channel strategy in `docs/PROJECT-README.md`

### 16. Shorts export
- Cut vertical Shorts from approved episode moments
- Save Shorts projects/exports under `shorts/`
- Keep branding and character consistency

## File organization rules

| Content | Location |
|---------|----------|
| Scripts & outlines | `scripts/` |
| Storyboards | `storyboards/` |
| Character art & rigs | `characters/<name>/` |
| Locations | `backgrounds/` |
| Props | `props/` |
| Shared misc assets | `assets/` |
| Voices | `voices/` |
| Music | `music/` |
| SFX | `sound-effects/` |
| Episode working files | `episodes/` |
| Masters / renders | `renders/` |
| Platform exports | `exports/` |
| Thumbnails | `thumbnails/` |
| Shorts | `shorts/` |
| Docs | `docs/` |
| Helper scripts | `tools/` |

---

## Studio operating principles

- Never delete important work without permission
- Prefer reusable production systems over one-off clutter
- Maintain character and visual consistency across episodes
- Avoid repetitive mass-produced content; prioritize original storytelling
- The human creator remains the final creative decision-maker

---

## Next step after foundation

When the creator is ready, the recommended first production step is:

1. Finalize character concepts in `docs/CHARACTER-BIBLE.md`
2. Lock a simple visual direction for Sunrise Valley
3. Only then begin Episode 1 ideation and scripting

# Remotion animation workspace

This folder is the code-driven animation pipeline for **Kito & the Wild Ones**.

- Stack: Remotion + React + TypeScript
- Studio docs remain in `../../docs/`
- Final series characters are NOT implemented here yet
- Current composition: `PipWalkWave` (technical test only)

## Commands

```bash
cd tools/animation
npm install
npm run start              # Remotion Studio preview
npm run render:pip-test    # Render Pip technical test to renders/tests/
```

Pip is a placeholder test character and must never join the official cast.
